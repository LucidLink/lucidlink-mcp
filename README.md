# LucidLink MCP Server - Release Notes

Release notes for the [LucidLink MCP server](https://pypi.org/project/lucidlink-mcp/),
which gives MCP-capable agents and IDEs secure, real-time access to files in a
LucidLink filespace.

- **Install:** `pip install lucidlink-mcp`
- **Docs:** [LucidLink Developer Portal](https://developer.lucidlink.com/)

Versions follow [Semantic Versioning](https://semver.org/); newest first.

## 1.0.1 - 2026-10-24

This update includes security fixes for a third-party certificate issue.

## 1.0.0 - 2026-10-20

The LucidLink MCP server is now generally available.

### General improvements
- Various bug fixes and performance enhancements for a smoother, faster, and more stable experience.
